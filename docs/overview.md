# slide-viewer の概要

## 何のためのものか

Web ページに、発表資料（PDF・PowerPoint）を **1枚ずつめくって見られる形で埋め込む**ための部品。
最初は自分のサイト（yoshito.me）のために作り、誰でも使えるよう汎用化して公開している（MIT ライセンス）。
使い方の説明は README（英語）と README.ja.md。docs/ は開発の記録。

- どのページにも同じ書き方で載せられるよう、**script タグ1行 + div 1つ**で動く
- 資料ごとに**ダウンロードの可否**を決められる
- ダウンロード不可の資料は、URL やデベロッパーツールからも元のファイルを取れないようにしてある
  （元の PDF をサーバーに置かず、ページ画像だけを置く。画像もマスを並べ替えて保存する）
- `slide-viewer/` フォルダをコピーするだけでどのサイトにも置ける。PHP の無い場所では静的モードで使える

## 主な機能

- 下に操作バー（前へ・ページ番号・次へ／サムネイル・ダウンロード・全画面）
- サムネイルボタンで、ページの一覧（サムネイル列）を開閉。押すとそのページへ移動
- ← → キー、PageUp/PageDown、Home/End、スワイプでページ送り
- 全画面表示（iPhone の Safari のように要素の全画面に対応していないブラウザでは、画面いっぱいに重ねて表示）
- 資料の縦横比（16:9・4:3 など）に合わせて表示。置いた場所の幅に合わせて縮む
- ライト／ダークモード対応
